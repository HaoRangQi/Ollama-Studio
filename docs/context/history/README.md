> 只放“当前已不适用、但值得追溯”的旧方案、旧状态或旧决策。当前事实不要写在这里。
>
> 需要追溯时先搜索本索引，再读对应文件；不默认遍历归档目录。

## 归档规则

- 文件名：`YYYY-MM-DD-主题.md`。
- 每条记录写清：背景、当时结论、为什么不再适用、当前替代来源。
- 不保存：完整聊天记录、逐条操作流水、密钥/令牌、个人设备私有路径。
- 归档后在下方索引表登记；当前状态由 `docs/context/NOW.md` 等权威文档负责。
