Cause: hasRunningDownloads() gates only the partial branch
(server/cache.ts:533-536). The temp branch (server/cache.ts:558-572) never
checks it, and the orphan branch (server/cache.ts:485-531) has neither an
active-download check nor a recent-mtime guard. scanTempDirs() also keys
recency on the directory mtime (server/cache.ts:353-356), which a long
download does not update after the initial file creation.
